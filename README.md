## ⚡ Démarrage Rapide

```bash
# 1. Cloner le dépôt
git clone https://github.com/YousefHarizi/Mission3_ArchitectureSI_GrpYoussef_4CCE11.git

# 2. Exécuter les tests unitaires
./mvnw clean test

# 3. Lancer l'application Spring Boot
./mvnw spring-boot:run
```
